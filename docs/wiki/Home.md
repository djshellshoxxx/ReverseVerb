# ReverseVerb Wiki

ReverseVerb generates reverse-reverb swells that rise into a one-shot hit (snare, hat, clap). Built with
JUCE 8 as VST3, CLAP and Standalone (AU on macOS). Current development is proprietary; see `LICENSE`.
