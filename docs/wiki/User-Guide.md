# User Guide

- **Build on Windows:** run `build.ps1` in PowerShell as Administrator. The plugin lands in the VST3 folder (README "Build (Windows)").
- **Build on macOS or Linux:** see the README "Build (macOS / Linux)" section.
- **Use:** load a hit, set the reverb (size, decay, diffusion, and so on), then play the swell. Use `<` and `>` to browse a folder.
- **Shape:** length, curve, colour (low pass), bass cut (high pass), volume envelope with tension, and pitch sweep (1/2/4 octaves).
- **Sync:** total length can follow host BPM (1, 2, 4, 8 beats or 1, 2, 4 bars).
- **Export:** drag the result into the DAW or export a WAV; batch export renders a whole folder with the current settings.
- **Presets:** factory and user presets, A/B compare, undo and redo (Ctrl/Cmd+Z, Ctrl/Cmd+Shift+Z).
- **Help:** press `?` in the plugin.
